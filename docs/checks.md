# Check catalogue

Every check has a stable code, such as `TEX005`, that appears in reports and in
`[checks] select` and `ignore`. Codes are never reused. To read one check's
scope and fix in the terminal, run `fledge rule CODE`; `fledge rules` lists all
of them.

```sh
fledge rules
fledge rule BIB101
fledge rule PDF104 --json
```

Checks fall into three groups:

- **On by default** checks run without configuration: TODO markers, unresolved
  citations and references, unused bibliography entries and TeX log problems.
- **Opt-in** checks need a setting from you, such as a page limit, a required
  document class or `require_embedded_fonts = true`. A [preset](configuration.md#start-from-a-preset)
  switches on a useful set at once. Fledge never invents a limit.
- **Always-enforced** guards keep the prepared copy safe and faithful, for
  example missing or out-of-project files and PDF preservation. They run
  whenever their stage runs, and ignoring their code does not switch them off.

A check that did not run, or could not decide, never counts as a pass. The
[glossary](glossary.md) defines the report terms used here.

## Families

| Family | What it covers |
| --- | --- |
| `TEX` | Source diagnostics and literal manuscript constraints |
| `MAN` | Manuscript, author, declaration and float checks |
| `BIB` | Bibliography structure, citation coverage and metadata; `BIB2xx` guard bibliography edits |
| `BLD` | TeX log problems, overflow tolerance and loaded-package policies |
| `PRV` | Identity terms, privacy hints, secrets and shell escape |
| `PKG` | Flattening safety, filenames, deliverables, archive size and template files |
| `PDF` | Page limits, page size, fonts, text, metadata, artwork and tagged structure |
| `NET` | Online DOI, metadata, notice and link checks |
| `CMP`, `FMT` | Preservation comparisons and formatting proposals |
| `RPT` | Review decisions and diagnostic exports |

Configure checks as described in [choose checks](configuration.md#choose-checks).
The example files {download}`checks.toml <../examples/checks.toml>` and
{download}`settings.toml <../examples/settings.toml>` show the settings tables.

## Conventions for configured checks

These conventions apply when you configure measurements, matching or templates.

**Units and coordinates.** PDF dimensions use PDF points (1/72 inch); build
overflow uses TeX points. Regions are measured from the top-left corner of an
unrotated, uncropped page, and margins are listed as left, top, right, bottom.
Section budgets use explicit inclusive page ranges; Fledge does not infer where
references or appendices start. Text-size rounding, unmeasured text and
unsupported transforms are reported as uncertainty. Overlap, sparse-page, stroke
and color findings stay advisory when the observation cannot establish intent.
Type 3 is a font type, not proof of bitmap glyphs.

**Metadata matching.** Top-level `match_source_pdf_metadata = ["title", "author"]`
compares unambiguous literal source values with the extracted PDF properties;
generated or ambiguous source values are inconclusive. Explicit expectations use
`[pdf_checks.expected_metadata]`. Choose one of the two for each field;
configuring both is an error.

**Template references.** In `submission_checks.template_references`, the
right-hand path resolves from the configuration file's directory and the
left-hand path names a file in the bundle, followed through flattening. Equality
with the supplied file does not establish authenticity, age or compatibility.

**Manuscript scope.** Manuscript checks follow literal source structures without
expanding arbitrary macros. Citation checks use one root unless
`bibliography_checks.all_roots` is set. Apparently uncited entries and unused
assets are review candidates, not deletion instructions. Source float order is
not rendered float order.

**Online results.** Service failures, restricted resources, no match and
ambiguous candidates are reported separately; no remote response rewrites the
bibliography. See [online evidence](configuration.md#select-online-evidence-deliberately).
