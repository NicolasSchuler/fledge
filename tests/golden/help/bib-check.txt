Usage: fledge bib check [OPTIONS] INPUT

  Check syntax, citation use and configured fields; online evidence is opt-in.

Common options:
  --config PATH                   Use this TOML settings file instead of discovering project
                                  configuration.
  --json                          Alias for --output-format json.
  --output-format [terminal|compact|json|html|ci]
                                  Terminal, agent-friendly compact, JSON, offline HTML or CI
                                  annotations.
  --quiet                         Suppress progress messages on stderr; the final report is still
                                  printed.
  --show-passed                   Also list passed findings and inventories.
  --show-files                    List every included and excluded submission file.
  --online / --offline            Allow configured DOI/URL checks to send public queries; offline by
                                  default.
  --main FILE                     Main .tex file of the document, relative to the input; needed when
                                  the input holds several documents.
  -h, --help                      Show this message and exit.

Advanced options:
  --isolated                     Ignore discovered configuration and use defaults.
  --html-report PATH             Save an escaped offline HTML report to a new file outside the
                                 input.
  --preview-output PATH          New directory for explicitly selected grayscale page previews.
  --diagnostics PATH             Export an explicitly unverified diagnostic ZIP of sanitized reports
                                 and diffs.
  --json-report, --report PATH   Also save the JSON report to a new file outside the input.
  --jobs INTEGER                 Most operations that may run at once on this computer; 1 runs them
                                 one after another (default 2).
  --build-jobs INTEGER           Most TeX builds that may run at once (default 1).
  --render-jobs INTEGER          Most PDF pages that may be rendered at once (default 1).
  --job-timeout-seconds INTEGER  Longest the whole run may take, in seconds, including time spent
                                 waiting (default 600).
  --timeout-seconds INTEGER      Longest one external tool, such as latexmk, may run, in seconds
                                 (default 120).
