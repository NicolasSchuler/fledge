Usage: fledge prepare [OPTIONS] INPUT

  Package the selected paper's needed inputs and explicit deliverables.

  Unrelated files are omitted from the copy; originals stay unchanged. Complete dependency evidence
  and an exact archive rebuild are required. Ship extra files with [package] include = [...] in
  project configuration.

Common options:
  -o, --output DIR                Folder for the verified submission copy: new or empty, and outside
                                  INPUT. Required unless --dry-run is given.
  -m, --main FILE                 Main .tex file of the document, relative to INPUT; needed when
                                  INPUT holds several documents.
  --preset [anonymous-review|arxiv|camera-ready]
                                  Apply an example preset beneath the settings file and command-line
                                  options; a starting point, not a compliance certification (fledge
                                  init --list).
  --select CODE_OR_PREFIX         Run only these checks: a check code (TEX001), a code prefix (TEX,
                                  BIB1) or ALL, in any case. Repeatable; replaces checks.select from
                                  configuration.
  --ignore CODE_OR_PREFIX         Skip these checks; same syntax as --select. Repeatable; adds to
                                  checks.ignore from configuration.
  --engine [pdflatex|xelatex|lualatex]
                                  TeX engine that builds the PDF (default pdflatex).
  --reference-pdf PATH            PDF that the build must match page by page, for example the
                                  version you already submitted.
  --max-pages PAGES               Total page limit, including references.  [x>=1]
  --layout [preserve|flat]        Keep the folder structure (preserve) or move every file to the top
                                  level (flat); default preserve.
  --format / --no-format          Apply tex-fmt to the separate copy.
  --dry-run                       Check and plan the edits without writing a submission copy; add
                                  --diff to see them.
  --diff                          Show the diff of every planned or applied edit.
  --online / --offline            Allow configured DOI/URL checks to send public queries; offline by
                                  default.
  --config PATH                   Use this TOML settings file instead of discovering project
                                  configuration.
  --json                          Print the report as JSON (the same as --output-format json).
  --output-format [terminal|compact|json|html|ci]
                                  How to print the report: terminal (default), compact records for
                                  scripts and agents, JSON, an HTML page, or CI annotations.
  -q, --quiet                     Suppress progress messages on stderr; the final report is still
                                  printed.
  --show-passed                   Also list passed findings and inventories.
  --show-files                    List every included and excluded submission file.
  -h, --help                      Show this message and exit.

Advanced options:
  --isolated                      Ignore discovered configuration and use defaults.
  --html-report PATH              Also save the report as an HTML page that opens offline, in a new
                                  file outside the input.
  --diagnostics PATH              Save a ZIP of the redacted report and diffs to share when asking
                                  for help; it is not a verified submission.
  --json-report, --report PATH    Also save the JSON report to a new file outside the input.
  --preview-output DIR            Folder for the grayscale page previews that the settings ask for:
                                  new or empty, and outside the input.
  --force                         Replace an output or preview folder that Fledge wrote earlier,
                                  once the new run has succeeded; any other existing folder is still
                                  refused.
  --jobs N                        How many operations may run at once; 1 runs them one after another
                                  (default: the number of CPUs, at most 4).  [1<=x<=64]
  --build-jobs N                  How many TeX builds may run at once (default 1).  [1<=x<=64]
  --render-jobs N                 How many PDF pages may be rendered at once (default: half the
                                  number of CPUs, from 1 to 4).  [1<=x<=64]
  --job-timeout-seconds SECONDS   Longest the whole run may take, in seconds, including time spent
                                  waiting (default 600).  [x>=1]
  --timeout-seconds SECONDS       Longest one external tool, such as latexmk, may run, in seconds
                                  (default 120).  [x>=1]
  --bibliography-backend [auto|bibtex|biber]
                                  Bibliography tool: bibtex, biber, or auto to detect it from the
                                  sources (default auto).
  --normalize-doi / --no-normalize-doi
                                  Normalize literal DOI prefixes.
  --cleanup / --no-cleanup        Remove known build debris from the copy before editing; files the
                                  paper needs are always kept (default on).

Examples:
  fledge prepare paper -o submission          Write the verified copy into submission.
  fledge prepare paper --dry-run --diff       Show the planned edits; write nothing.
  fledge prepare paper -o submission --force  Replace the copy of an earlier run.
